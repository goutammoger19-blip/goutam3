# Birthday 3D Website — Version 2

This version follows the uploaded reference video's sequence and visual language more closely:
1. Dark romantic browser-style frame
2. Birthday intro
3. Date lock / 13:41 screen
4. "Oops" wrong-date interaction
5. Birthday cake + wish
6. Cute Memories photo cards
7. Pop the Wishes balloons
8. Birthday Puzzle
9. One Last Surprise gift
10. Letter Just For You

## Customize
Edit `script.js`:
- `NAME`
- `BIRTHDAY`
- `LETTER`

## Add photos
Replace the fake photo cards in `index.html` with your own images from `assets/photos/`.
A simple image can be used as:
`<img src="assets/photos/photo1.jpg" alt="Memory">`

## Add music
Put your own legally obtained audio file at:
`assets/music.mp3`

Browsers normally require the visitor to tap the music button before audio can start.

## Run
Open `index.html` in Chrome/Edge/Firefox.

## Publish
Upload the folder to GitHub Pages, Netlify, Vercel, or another static host.
